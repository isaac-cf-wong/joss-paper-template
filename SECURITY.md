# Security Policy

We appreciate responsible disclosure of security vulnerabilities. If you find a
vulnerability in this repository, please report it using GitHub's private
vulnerability reporting feature.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it via **GitHub's
"Report a vulnerability" feature**:

1. Go to the
   [Security](https://github.com/isaac-cf-wong/joss-paper-template/security) tab
2. Click **"Report a vulnerability"**
3. Describe the vulnerability, steps to reproduce, affected versions, and your
   OS

**Please do not open a public issue.** GitHub's private vulnerability reporting
keeps the issue confidential until a fix is available.

## Response Timeline

We aim to:

- Acknowledge receipt within **24 hours**
- Investigate and assess the vulnerability within **3–5 business days**
- Provide a security patch in a timely manner
- Credit the reporter (if desired)
